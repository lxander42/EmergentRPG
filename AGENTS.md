# Project instructions

- This is a fresh Unity/Blender project. Read `README.md` and the pinned editor version before working.
- Keep changes focused on the requested feature. Add gameplay systems only when needed.
- Use `UnityProject` as the Unity project path, not the repository root.
- Keep editable Blender files in `ArtSource`; export runtime assets into `UnityProject/Assets`.
- Commit `.meta` files with their Unity assets. Do not commit Library, Temp, build output, logs, credentials, or machine-specific tool paths.
- Use Git LFS for the binary formats listed in `.gitattributes`.
- Prefer the official Unity CLI for editor automation. Check its installed `--help` before relying on experimental commands.
- Verify changes in the pinned Unity editor. Report any compile, import, test, or build step that could not be run.
